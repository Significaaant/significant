Conseils préalables sur vos données (format, décimales, valeurs manquantes)
1. Nettoyage des données

Format propre requis :

  • Décimales avec un point (ex : 1.75).
  • Pas d'espaces inutiles dans les cellules.
  • Cases vides pour les données manquantes (NA).
2. Nature des variables

Distinguez bien :

  • Identifiant : Ne pas analyser.
  • Catégorie : 1 = Homme (code, pas un chiffre).
  • Score : 12/20 (vrai nombre mesurable).
3. Valeurs extrêmes

Attention aux erreurs :

  • Un âge de 150 ans ? Supprimez-le.
  • Une taille de 10 m ? Corrigez-la.
